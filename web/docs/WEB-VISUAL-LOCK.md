## Referencia principal

La composición promocional aprobada de Mágina Olivo es la referencia canónica para toda la web.

No debe reinterpretarse hacia otro estilo visual salvo decisión explícita.

## Identidad bloqueada

### Paleta
- crema cálido / papel natural;
- verde olivo;
- verde bosque profundo;
- blanco roto;
- dorado/tierra únicamente como acento.

### Fotografía
- olivar mediterráneo realista;
- Sierra Mágina como contexto territorial;
- luz cálida y natural;
- agricultor adulto trabajando de forma creíble;
- primeros planos de ramas, aceitunas, manos y móvil;
- evitar estética de banco de imágenes genérica.

### Tipografía
- serif editorial para titulares;
- sans-serif limpia para interfaz y textos funcionales;
- manuscrita únicamente como acento emocional breve.

### Composición
- grandes imágenes panorámicas;
- cortes orgánicos y ondas crema entre escenas;
- hojas de olivo decorativas en bordes, nunca invadiendo contenido;
- tarjetas suaves y discretas;
- móviles con las pantallas canónicas de la app;
- alternancia de fotografía, espacio en blanco y producto.

## Home — orden visual bloqueado

1. Hero: agricultor + móvil + Sierra Mágina.
2. Territorio: paisaje panorámico.
3. Historia/personas: agricultor entre olivos.
4. Del campo al móvil: mano + teléfono.
5. Secuencia cinematográfica campo → persona → teléfono.
6. Explicación scroll de funciones.
7. Vista conjunta de cinco pantallas.
8. Beneficios.
9. Sierra Mágina / territorio.
10. CTA final de la app.
11. Footer.

## Movimiento

El diseño estático sirve como storyboard, pero la web final debe sentirse continua.

### Principios
- no usar saltos bruscos;
- no animar todo a la vez;
- el scroll controla la narrativa;
- el paisaje se acerca antes de que aparezca el móvil;
- el móvil entra progresivamente desde contexto real;
- cuando el producto toma protagonismo, el fondo se simplifica;
- las transiciones entre secciones usan máscaras/ondas y solapamiento visual;
- duración visual larga: cada momento importante debe poder “respirar”.

### Campo → móvil
Secuencia mínima:
1. paisaje;
2. agricultor;
3. acercamiento;
4. observación del olivo;
5. mano;
6. móvil parcialmente visible;
7. móvil completo;
8. giro frontal;
9. pantalla encendida;
10. interfaz Mágina Olivo.

### Producto
Las pantallas no aparecen como capturas independientes. El teléfono permanece visualmente relacionado con el paso anterior y la interfaz cambia con el scroll.

## Pantallas canónicas

Orden:
1. Bienvenida.
2. Tus fincas y parcelas.
3. Mapa y Catastro.
4. Actividad y campaña.
5. Cosecha, gastos y documentos.
6. Tiempo, mercado y alertas.

Las futuras implementaciones deben respetar la composición y contenidos aprobados de estas pantallas.

## Responsive

### Escritorio
- narrativa panorámica;
- teléfono sticky;
- contenido lateral;
- fila de cinco teléfonos visible cuando haya espacio.

### Tablet
- teléfono sticky;
- texto más compacto;
- overview en 2–3 columnas.

### Móvil
- el teléfono permanece protagonista;
- la vista conjunta de pantallas se convierte en carrusel horizontal;
- reducir capas visuales, no contenido;
- mantener titulares editoriales y ritmo vertical.

## Exactitud del producto

La web no debe anunciar funciones o plataformas que todavía no existan como disponibles.

En particular, mientras Mágina Olivo sea un producto Android:
- Google Play puede mostrarse como destino previsto;
- no mostrar disponibilidad real en App Store;
- usar “próximamente” mientras no exista publicación efectiva.

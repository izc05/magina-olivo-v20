# WEB V3 — Dirección creativa

Estado: **en revisión — Gate V3-A pendiente**
Alcance: issue [#389](https://github.com/izc05/magina-olivo-v20/issues/389), subordinado al Visual Lock [#394](https://github.com/izc05/magina-olivo-v20/issues/394).

## Brief aprobado

La Home debe presentar Mágina Olivo como producto agrícola premium mediante una secuencia cinematográfica de campo a producto. La fotografía lleva el peso visual; el texto aparece en mensajes breves y la interfaz del producto entra progresivamente en la misma escena. La referencia de composición, paleta, tipografía y cierre es #394 y no se reinterpretará.

## Dirección

- **Tono:** agrícola real, adulto, sereno y preciso; luz natural de primera hora, fotografía sobria y editorial.
- **Paleta:** crema natural, verde olivo profundo y blanco roto. Tierra/dorado solo como acento tenue; el color de la fotografía domina las escenas.
- **Tipografía:** serif editorial para titulares cortos; sans limpia para UI y lectura funcional.
- **Cámara:** avance lento y continuo desde el olivar hacia el gesto y el móvil. El movimiento expresa observación y decisión; no es parallax decorativo.
- **Producto:** el móvil nace físicamente en la escena. La pantalla toma el control en el takeover y después la interfaz se representa como DOM, sin simular servicios reales.
- **Continuidad:** una persona, manos, vestuario, teléfono, olivares y dirección de luz consistentes en todos los planos.
- **Composición:** una idea por acto, mucho aire, interfaces legibles y sin densidad de portal.

## Narrativa y copy

1. Campo — «Tu olivar cambia cada día.»
2. Observación — «Lo ves. Lo decides.»
3. Gesto — «Y lo registras.»
4. Producto — la continuidad campo → móvil → Mágina Olivo.
5. Decisiones — mostrar funciones y datos de producto sin cifras inventadas.
6. Escritorio — demo claramente rotulada «Próximamente»; sin prometer sync productivo.
7. Cierre — «Tu olivar, claro y al día.» con los CTA aprobados en #394.

## Límites

- No usar Home V1/V2, sus fotografías, copy, mocks de teléfono ni CinematicHomeV2.
- No usar stock genérico ni vídeo de fondo pesado.
- No mostrar cifras, clima, mercado o actividad como datos reales. Toda UI conceptual debe rotularse Demo.
- No implementar la secuencia final ni producir una secuencia extensa hasta aprobar los keyframes y la continuidad en Gate V3-A.
- El primer material de review se considera concepto, no fotografía de producción ni asset aprobado.

## Gate V3-A

La dirección se considera aprobada solo cuando se revisen K01–K12 y queden aprobados estilo, hero desktop/móvil, continuidad de personaje, gesto campo→móvil y dirección del teléfono/producto. El estado actual de cada keyframe se mantiene visible en [/v3-review](/v3-review).

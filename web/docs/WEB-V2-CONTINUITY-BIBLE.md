# Mágina Olivo Web V2 — Continuity Bible

Estado: **CANONICAL FOR G1/G2 VISUAL PRODUCTION**  
Fecha: 2026-09-21

Objetivo: asegurar que K01–K24 se perciban como una única película y no como imágenes independientes.

## 1. Agricultor

Debe mantenerse el mismo personaje durante:
- K01–K12;
- K23–K24.

Bloquear:
- edad aparente;
- complexión;
- tono de piel;
- pelo/barba si son visibles;
- manos;
- altura relativa;
- postura corporal.

No se acepta:
- cambio de rostro entre frames;
- manos con anatomía distinta;
- cambio notable de edad;
- cambio de complexión;
- pose publicitaria mirando a cámara.

## 2. Vestuario

Paleta:
- verde oliva apagado;
- gris piedra;
- marrón tierra;
- azul muy desaturado como máximo secundario.

Evitar:
- rojo vivo;
- naranja intenso;
- logos;
- ropa demasiado limpia/publicitaria;
- sombrero/gorra que aparezca y desaparezca.

Una vez aprobado K01:
- chaqueta/camisa bloqueada;
- pantalón bloqueado;
- botas bloqueadas;
- accesorios bloqueados.

## 3. Teléfono

Debe ser exactamente el mismo dispositivo en:
- K07–K13;
- K23 si vuelve a aparecer.

Especificación visual:
- negro/grafito;
- marco fino;
- esquinas redondeadas;
- sin marca visible;
- cámara discreta;
- proporción moderna;
- sin funda llamativa.

El paso K09 → K10 → K11 → K12 debe parecer un único movimiento físico.

## 4. Luz

Escena de campo:
- golden hour suave / primera hora;
- cálida, natural;
- sombras blandas;
- no HDR;
- no cambios bruscos de dirección de luz.

Bloquear:
- dirección principal;
- temperatura aproximada;
- intensidad;
- contraste.

No pasar de:
“mañana cálida”
a:
“mediodía duro”
sin transición explícita.

## 5. Olivar

Debe mantener:
- olivos adultos;
- densidad coherente;
- suelo seco/mediterráneo;
- profundidad real;
- sin hitos territoriales reconocibles.

No usar:
- monumentos;
- pueblos identificables;
- Sierra Mágina como protagonista;
- carteles;
- matrículas legibles.

## 6. Manos y aceitunas

K03–K09 son especialmente sensibles.

Reglas:
- cinco dedos anatómicamente correctos;
- tamaño de mano consistente;
- piel coherente con agricultor;
- aceituna picual/mediterránea creíble;
- rama y fruto sin deformaciones;
- no duplicar dedos/frutos de forma imposible.

## 7. Cámara

Lenguaje:
- estable;
- cinematográfico;
- sin saltos imposibles;
- movimiento físico comprensible.

K01–K06:
- plano general → medio → detalle.

K07–K12:
- detalle → móvil contextual → acercamiento → frontal.

No saltar:
- de izquierda a derecha sin motivación;
- de 35 mm a ultra gran angular agresivo;
- de altura de ojos a cenital.

## 8. Color grade

Base:
- verdes oliva;
- tierra cálida;
- crema;
- negro verdoso;
- piel natural.

Evitar:
- verdes fluorescentes;
- teal & orange extremo;
- cielos saturados;
- negros aplastados;
- exceso de claridad.

## 9. UI del teléfono

Debe coincidir con la aplicación canónica.

Bloquear:
- logo;
- paleta;
- tipografías;
- radios;
- iconografía;
- navegación;
- proporciones.

No inventar funciones fuera del roadmap aprobado.

## 10. Check visual por keyframe

Antes de marcar un asset como `candidate`:

- [ ] mismo agricultor;
- [ ] mismo vestuario;
- [ ] misma luz;
- [ ] manos correctas;
- [ ] mismo teléfono si aparece;
- [ ] composición coherente con frame anterior/siguiente;
- [ ] sin texto incrustado;
- [ ] sin marcas/logos accidentales;
- [ ] sin elementos territoriales excluyentes;
- [ ] calidad suficiente para fullscreen.

Antes de marcar `final`:
- [ ] desktop aprobado;
- [ ] mobile aprobado;
- [ ] transición con vecinos comprobada;
- [ ] compresión final hecha;
- [ ] QA visual en Pages realizado.

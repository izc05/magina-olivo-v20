# RC1.2 Naming Gate — Public Product Name

**Status:** OPEN  
**Purpose:** select the public brand without contaminating domain architecture or repeatedly renaming Android technical identifiers.

## Product-name requirements

The name should:

- relate naturally to olive growing / olive farms;
- work beyond Jaén and Sierra Mágina;
- be understandable or pronounceable in Spain;
- preferably remain usable internationally;
- avoid sounding like a general multi-crop ERP unless intentionally chosen;
- be short enough for Android launcher/store use;
- support a clean icon/logo;
- be distinctive enough for search/store discovery.

## Explicitly retired

- Mágina Olivo — retired as final public brand because the product is no longer geographically limited.

## Preliminary conflict screen — 2026-09-18

Do **not** adopt without a deeper legal/domain/store check:

- MiOlivar — an existing olive-farm management service is already using this name.
- OliveSuite — an existing olive-management app.
- Olearia — an existing olive-agritech product.
- Olicontrol — prior agricultural software/project usage exists.
- Olivara — multiple olive/oil brands already use it.
- OleaCampo — existing agricultural company name surfaced in Portugal.
- OlivaCore / Olivacore — existing commercial use and olive-variety terminology surfaced.

This is a preliminary web/product screen, **not** trademark clearance.

## Promising naming directions for deeper screening

These are working directions only, not approved names:

- OleaTrack

Before selecting any candidate:

1. Google/web exact-name screen.
2. Google Play / App Store screen.
3. OEPM/EUIPO trademark screen when appropriate.
4. domain availability.
5. social handle availability when useful.
6. pronunciation/spelling check in Spanish.
7. basic international meaning check.
8. final user approval.

## Technical naming rule

Until this Gate closes:

- repo may remain `izc05/magina-olivo-v20`;
- current Android package/namespace is a temporary engineering identifier;
- reference UI uses a neutral placeholder;
- do not create final store artwork;
- do not repeatedly rename package IDs.

Once approved, perform one controlled branding migration and rerun build/migration/installation tests.
